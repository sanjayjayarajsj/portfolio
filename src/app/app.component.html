About me

Engineering resilient back ends and fluid interfaces from Kerala, India.

I'm a full stack developer dedicated to building responsive, high-performance web products from database to browser. I craft front ends with Angular, TypeScript, and clean modern CSS, backed by solid server architectures in C#, ASP.NET Core, and Clean Architecture.

Whether writing high-throughput REST APIs, designing efficient schemas in SQL Server with EF Core and Dapper, or automating cloud deployments through Azure, AWS, and CI/CD pipelines, I prioritize code that is clean, testable, and built to scale.

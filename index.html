About me

A developer from Kerala who cares about how things look, feel and perform.

I'm a full stack developer. I build responsive, user-friendly web apps end to end: interfaces with HTML, CSS, JavaScript, TypeScript, Angular and Tailwind CSS, and back ends with C#, ASP.NET Core, MVC and microservices built on Clean Architecture, backed by SQL Server, EF Core and Dapper.

I also deploy and automate with Azure, AWS and CI/CD pipelines, so the work goes from commit to production reliably.

Outside of code I read tech blogs, play video games and try out new tools. I like clean, readable code and interfaces that people can use without thinking about them.
